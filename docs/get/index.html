Daily Sticky Note

A tiny always-on-top sticky note for your day: tasks with reminders, a Focus Mode timer, points for finishing things, and a gentle daily nudge. Local-first - no account, nothing to set up.

  • Floats above every window, lives in your tray
  • Focus Mode: pick a task, roll a timer, switch when it rings
  • Drag to reorder, earn points, level up
  • English, Español, Français, Deutsch
  • Updates itself - install once

Install the desktop app

macOS
Apple Silicon (.dmg) Intel (.dmg)
curl -fsSL https://raw.githubusercontent.com/amarcu/daily-sticky-note/main/install.sh | bash
Windows
Installer (.exe) MSI
irm https://raw.githubusercontent.com/amarcu/daily-sticky-note/main/install.ps1 | iex
Linux
AppImage .deb .rpm
curl -fsSL https://raw.githubusercontent.com/amarcu/daily-sticky-note/main/install.sh | bash

Fetching the latest version…

These builds are unsigned, so your OS warns once about an "unidentified developer" - right-click > Open on macOS, or "More info > Run anyway" on Windows. After that the app keeps itself up to date.
